# Regression Corpus

This corpus tests whether the system improves editorial quality without flattening legitimate voice or altering meaning.

## Required sample classes

1. Generic AI-generated corporate prose
2. Strong human prose containing supposed AI tells
3. One author across several registers
4. Weak human writing
5. High-quality AI-assisted writing
6. Literary fragments and parataxis
7. Elaborate literary syntax
8. Second-language English
9. Investor communication
10. Strategic consulting writing
11. Marketing copy
12. Technical documentation
13. Policy and legal-adjacent writing
14. Mixed human and AI documents
15. Quote-heavy research writing
16. Personal reflection
17. Institutional or multi-author writing
18. Presentation narrative and slide headlines

## Test operations

Each sample should be tested through:

- audit only
- minimal edit
- full rewrite control
- voice-profile edit
- no-profile edit
- alternate platform adapters
- factual verification
- final editorial gate

## Evaluation dimensions

- semantic fidelity
- argument fidelity
- factual and source fidelity
- voice and register fidelity
- anti-slop reduction
- edit economy
- protected-trait preservation
- epistemic calibration
- distinctiveness
- reader trust
- false-positive edit rate
- cross-platform consistency

## Initial acceptance rule

A governed output must not pass when it improves surface fluency by materially changing meaning, certainty, attribution or a protected voice characteristic.
