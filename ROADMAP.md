# Roadmap

## v0.1 Foundation

- Establish the canonical repository structure.
- Publish the Editorial Integrity Router Skill.
- Define and validate the Project Editorial Manifest.
- Document proportional workflow routing across writing forms.

## v0.2 Core authorship intelligence

- Authorship Capture Skill.
- Voice Profile Builder Skill.
- Audience and Register Profile schemas.
- Editorial Brief Compiler Skill.
- Initial personal, brand and institutional profile examples.

## v0.3 Editorial production

- Argument and Structure Reviewer.
- Anti-Slop Auditor.
- Voice-Preserving Editor.
- Factual and Attribution Verifier.
- Final Editorial Gate.

## v0.4 Multi-form production

- Email and Message Writer.
- Report and White-Paper Writer.
- Presentation Narrative Architect.
- Article and Essay Writer.
- Book and Manuscript Architect.
- Continuity Keeper.

## v0.5 Evaluation and portability

- Regression corpus.
- Human review rubric.
- False-positive edit measurement.
- Cross-platform smoke tests.
- ChatGPT, Codex, Claude, Gemini, Cursor and Copilot adapters.

## v1.0 Production release

- Stable constitutional rules.
- Versioned schemas and migration guidance.
- Automated validation and packaging.
- Governance and release process.
- Privacy, retention and profile ownership controls.

## Longer-term research

- Retrieval over approved writing samples.
- Style and authorship embeddings.
- Multilingual voice profiles.
- Provenance and disclosure modes.
- Adaptive profiles based only on explicitly approved edits.
