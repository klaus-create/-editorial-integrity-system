# Quality Gate

## Mandatory checks
- [ ] Accountable author, assignment and intended reader effect are identified.
- [ ] Every source has a reference, permission status and relevant limitation.
- [ ] The thesis is authorised, proposed_for_confirmation or unresolved.
- [ ] Compound claims are atomised where their evidence duties differ.
- [ ] Every material item has an epistemic class and publication status.
- [ ] Confidence is not used as a substitute for evidence quality.
- [ ] Contradictions and disagreements remain visible.
- [ ] Personal recollections and first-person experiences are not upgraded to fact.
- [ ] Protected language includes a preservation reason.
- [ ] Prohibited inventions cover missing examples, experiences, quotations and statistics.
- [ ] Sufficiency distinguishes outline, drafting and publication needs.
- [ ] The embedded claim registry matches the source pack assignment, status, human-action flag, substantive item IDs and source references, and the complete output validates against the source-pack schema.

- [ ] Exact input versions are recorded for every material upstream artefact.
- [ ] No stale input is treated as current, and the output states its own invalidation conditions.

## Failure outcomes
- `conditional`: an outline or marked draft may proceed with explicit gaps.
- `human_input_required`: thesis, experience, permission or contradiction requires the author.
- `blocked`: proceeding would require invention or unauthorised disclosure.

## Evidence to return
Return the source inventory, classified items, contradiction log, sufficiency decision and unresolved issue owners.

## Final self-check
Did I add any proposition the author did not supply? Did I erase uncertainty to make the pack coherent? Can a drafter tell exactly what may be asserted, attributed, inferred or omitted?
