# Specialist Method

## Executability
Full drafting requires authorised thesis, known audience/form, status for material claims, available sources or permitted placeholders, and authorised first-person experience. Otherwise return outline, questions or conditional draft only.

## Claim-to-section map
For each section record function, claims, evidence/source, inference level, reader question and transition.

## Evidence moves
Direct evidence; attributed view; explicit author judgement; labelled inference after evidence. Never use confidence to hide weak support.

## Gap markers
[SOURCE REQUIRED], [AUTHOR DECISION], [EXAMPLE REQUIRED], [CURRENT VERIFICATION REQUIRED]. Remove only when resolved.

## Form playbooks
Email: decision/request before secondary context. Social: specific tension or useful promise, no formulaic hook. Report: observation, interpretation, implication and recommendation separated. Proposal: problem, value, approach, proof and decision. Presentation: one idea per slide; headline states point; speaker narrative separate. Article: earned thesis and counterpoint. Speech: breath, delivery and memory. Book: chapter promise, continuity and purposeful repetition.

## Regeneration threshold
Local repair first. Redraft paragraph only if function/logic/evidence mapping fails; section only if local repair cannot solve; whole piece only if architecture is unusable or user requests it.
