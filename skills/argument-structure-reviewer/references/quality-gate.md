# Quality Gate

## Mandatory checks
- [ ] Draft version and review scope are explicit.
- [ ] Thesis, narrative promise or decision is identified or marked unresolved.
- [ ] Claims, premises, evidence, warrants and conclusion are distinguished.
- [ ] Causal language is tested against mechanism, timing and alternatives.
- [ ] Credible counterarguments are considered proportionately.
- [ ] Local, section, whole-piece and larger-work issues are separated.
- [ ] Repetition is assessed for function before being treated as duplication.
- [ ] Every P0 or P1 finding cites an observable defect and consequence.
- [ ] Severity and confidence are independent.
- [ ] Genre irregularity is not penalised merely for being unconventional.
- [ ] Findings remain diagnoses and do not include silent replacement prose.
- [ ] Output validates against the argument-review schema.

- [ ] Exact input versions are recorded for every material upstream artefact.
- [ ] No stale input is treated as current, and the output states its own invalidation conditions.

## Failure outcomes
- `conditional`: review is useful but limited by missing brief, evidence or context.
- `human_input_required`: thesis or accountable decision is unresolved.
- `blocked`: the supplied draft is too incomplete or inconsistent to review responsibly.

## Evidence to return
Return the argument map, finding locations, quoted or paraphrased evidence, consequence, severity, confidence and repair direction.

## Final self-check
Would each finding survive a change in stylistic taste? Did I diagnose the logical bridge rather than merely dislike the sentence? Have I remained outside editing authority?
