# Quality Gate
Pass only when all material claims are atomised, evidence burden matches class and consequence, sources pass four tests, figures/units/denominators/calculations are checked, quotes are checked against originals where possible, conflicts remain visible, current claims use current sources, every claim has status/action and factual edits did not silently alter thesis.

Self-check: Did I verify the claim rather than repeated wording? Is source authoritative for this exact proposition? Did I preserve fact/judgement/inference distinctions? Can a sceptical reviewer reproduce the check?
