# Quality Gate
Pass only when whole-piece context was considered, findings identify consequence, clusters outrank isolated signals, protected irregularity was checked, severity and confidence are separate, preserve/query decisions appear where appropriate, origin claims are absent and audit remains separate from editing.

False-positive check: Is it functional in genre? Characteristic of author? Would changing it reduce meaning/rhythm/distinctiveness? Is harm observable? Omit low-confidence P3 unless exhaustive review is requested.
