# Specialist Method

## Distinguish
Objective = what work must accomplish. Reader effect = what reader should understand/decide/feel/do. Thesis = governing proposition. Message = surface articulation. Call to action = requested next step. Do not collapse them.

## Precedence
Safety/legal/privacy/source constraints; verified facts and quotations; human thesis; explicit assignment; project manifest; voice/register; audience/form; local improvement. Record conflicts rather than hiding them.

## Form architecture defaults
Email: context, answer/request, action, timing. Report: question, evidence, interpretation, implication, recommendation. Proposal: problem, value, approach, proof, next step. Presentation: one idea per slide and narrative movement. Article: framing, thesis, development, counterpoint, conclusion. Book chapter: chapter promise, movement and manuscript contribution.

## Readiness
Missing thesis stops drafting. Missing material source permits placeholders only if authorised. Missing audience blocks register optimisation. Missing high-risk approval owner blocks release. Impossible format limits require an explicit trade-off, not unreadable compression.
