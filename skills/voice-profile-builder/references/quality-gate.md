# Quality Gate

## Mandatory checks
- [ ] Permission and intended use are explicit.
- [ ] Every sample has an ID, form, date, authorship confidence, editing history and inclusion decision.
- [ ] Sufficiency is provisional, adequate or strong with a rationale.
- [ ] Every evidence reference resolves to an included sample, and every enduring trait has evidence from at least two independent samples.
- [ ] Counterevidence was actively sought and recorded.
- [ ] Topic, domain terminology and organisational policy are not mislabelled as voice.
- [ ] Enduring, register-specific, context-dependent and candidate traits are separated.
- [ ] Each accepted trait produces an actionable instruction and anti-pattern.
- [ ] Protected characteristics state the consequence of removal.
- [ ] Phrase copying and living-author mimicry are prohibited.
- [ ] Update rules require confirmed human evidence or explicit acceptance.
- [ ] Output validates against the voice-profile schema.

- [ ] Exact input versions are recorded for every material upstream artefact.
- [ ] No stale input is treated as current, and the output states its own invalidation conditions.

## Failure outcomes
- `conditional`: a provisional profile may guide low-risk work with visible limits.
- `human_input_required`: ownership, permission or accepted-edit evidence is unresolved.
- `blocked`: the request requires non-consensual profiling or close imitation.

## Evidence to return
Return the sample assessment, trait evidence, counterevidence, register boundaries and imitation constraints.

## Final self-check
Would the profile change a concrete writing or editing decision? Could another analyst reproduce each trait from the samples? Have I described behaviour rather than identity?
