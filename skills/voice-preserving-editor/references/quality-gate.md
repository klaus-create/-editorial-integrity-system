# Quality Gate

## Mandatory checks
- [ ] Original version, requested outcome and maximum edit authority are explicit.
- [ ] Preservation baseline includes meaning, evidence, attribution, voice and protected language.
- [ ] Every change has an observable problem and consequence.
- [ ] The lowest sufficient edit level was used.
- [ ] No fact, quotation, example, source or first-person experience was invented.
- [ ] Certainty, causal force, attribution and emotional stance did not drift silently.
- [ ] Compression retained material evidence, limitations and counterargument.
- [ ] Expansion used only authorised substance.
- [ ] Material paragraph propositions were compared before and after.
- [ ] Levels 4 to 6 are disclosed, authorised, linked to a stable edit ID and assigned downstream re-review actions.
- [ ] Unresolved factual or structural issues are escalated rather than edited around.
- [ ] Output validates against the edit-output schema.

- [ ] Exact input versions are recorded for every material upstream artefact.
- [ ] No stale input is treated as current, and the output states its own invalidation conditions.

## Failure outcomes
- `conditional`: revised text is useful but named upstream issues remain.
- `human_input_required`: substantive or transformative change requires author authority.
- `blocked`: the request requires invention, contradicts verified evidence or exceeds permissible editing.

## Evidence to return
Return revised text, edit levels, justifications, before/after propositions for material changes, drift checks and unresolved issue owners.

## Final self-check
Is the result recognisably the same authorial act unless transformation was requested? Did any apparently small edit change what the piece claims? Could a smaller repair have worked?
