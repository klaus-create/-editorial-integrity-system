# Quality Gate
Pass only when authority is clear, the lowest sufficient edit level was used, no fact/experience/quote/example was invented, certainty/attribution/causality did not drift, protected traits were checked, material edits are disclosed, unresolved factual/structural issues were escalated and the result remains recognisably the same authorial act unless transformation was requested.

For each material paragraph, state original and revised proposition; they must match unless substantive change was authorised.
