# Capability Depth Standard

A Skill is not specialist-capable merely because it names a good workflow. Stable Skills must include: intake sufficiency; explicit branching and stop logic; bounded authority; non-obvious method; structured outputs; calibrated positive, negative and false-positive cases; quality gate and self-check; adversarial tests; self-contained package references; and real-pilot evidence before production status.

Maturity: scaffold -> method-complete -> pilot-tested -> measured -> production. The v0.2 depth release is method-complete, not yet pilot-tested or production-proven.
